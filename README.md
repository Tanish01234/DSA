## Overview


This repository contains the practical implementations completed during the **Fundamentals of Data Structures & Algorithms (CSUC201)** laboratory course at **CHARUSAT**. Each practical is implemented in **C++** with a focus on clean coding practices, proper documentation, and understanding core data structures and algorithms. The repository serves as a semester-wise record of laboratory work and a reference for learning fundamental DSA concepts.
